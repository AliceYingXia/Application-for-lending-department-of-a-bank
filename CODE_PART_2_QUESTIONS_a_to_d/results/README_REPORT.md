## Key Findings

### Model Comparison (`comparison_summary.txt`)

| Metric | Gemini 2.5 Flash | Traditional |
|---|---|---|
| Mean sMAPE | 43.46% | 36.53% |
| Median sMAPE | 29.93% | 30.80% |
| IS Mean sMAPE | 44.70% | 40.75% |
| BS Mean sMAPE | 41.90% | 33.18% |
| Head-to-head wins | 26 / 50 (52%) | 24 / 50 (48%) |
| Paired t-test p-value | **0.2604 — not significant** (α = 0.05) |

### Ensemble Results (`ensemble_summary.csv`)

| Method | Mean sMAPE | Median sMAPE |
|---|---|---|
| Simple Average (50/50) | **24.14%** | 10.73% |
| Weighted (30% Gemini) | 27.55% | 12.34% |
| Weighted (20% Gemini) | 29.95% | 12.66% |

The 50/50 simple average is the best ensemble — a **33.9% improvement** over the better individual model.

### Thinking Mode (`thinking_comparison_report.txt`)

| Config | Temp | CV (avg) | Latency | Thinking Tokens |
|---|---|---|---|---|
| No Thinking | 0.0 | 0.00% | ~2.1s | 0 |
| No Thinking | 0.7 | ~5.7% | ~2.1s | 0 |
| With Thinking | 0.0 | ~9.7% | ~20.6s | ~4918 |
| With Thinking | 0.7 | ~10.1% | ~21s | ~4918 |

Thinking mode adds **10× latency** and **increases forecast variance** without improving accuracy. Not recommended for production.
